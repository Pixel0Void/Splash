# Splash (Roller Splat Clone)

🌀 A Unity-based clone of the popular mobile game **Roller Splat**, built for educational purposes.

## 🎮 About the Game

_Splash_ is a minimalist puzzle game inspired by **Roller Splat** by Voodoo. Players swipe to move a paintball through a maze, aiming to cover all paths with paint while solving movement-based puzzles.

This project is a non-commercial, fan-made clone to explore Unity development, game physics, and level design.

## 🚀 Getting Started

### Requirements

- **Unity Editor** – Recommended version: `Unity 2019.4.10f1` or newer

### Run the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/Pixel0Void/Splash.git
   ```
2. Open the project in Unity Hub.
4. Press **Play** to start testing.
